# Software and data releases

## 1.9.0 — 2026-11-09

Reproducible numerical implementation of the $A_C(k)=1$ reference detector-response model.

- Deterministic 99-point classification and seven moment-deformation scans.
- Magnetic and charge bounds with covariance-sensitive distance calculations.
- Thirty-three constructed overlap paths and independent response checks.
- Twenty-one finite-basis QCQPs and twelve positive numerical SOS bounds.
- Seeded 48-segment search, saved profiles, independent quadrature and convergence data.
- Cross-platform reproduction commands and continuous numerical regression tests.

The source-control history retains numerical development records for provenance. Use the fixed source revision in [CITATION.cff](CITATION.cff) to identify reproducible results.
